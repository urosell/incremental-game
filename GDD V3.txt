CONCIENCIA DE CLASE — Game Design Document v3.0
════════════════════════════════════════════════════════════

CONCEPTO
────────
Juego incremental / idle híbrido con temática de organización
popular y crítica al capitalismo. El jugador empieza solo,
agitando en su barrio, y construye progresivamente un movimiento
global. Tono irónico con fondo serio, texto narrativo en
momentos clave.

Recurso principal: Conciencia de Clase ⚡


MECÁNICA CORE
─────────────
Capa 1 — El clic manual
  Botón "¡Agitar!" genera 1 ⚡ por clic.
  Es la única fuente de recursos al principio.

Capa 2 — Los colectivos
  Con suficiente ⚡ construyes colectivos que generan
  automáticamente. El clic sigue existiendo pero es opcional.

Capa 3 — La Revolución
  Cuando la Conciencia Total acumulada llega a 10.000B
  puedes declarar La Revolución. Resetea todo pero otorga
  Legado Revolucionario permanente. Es cíclico e ilimitado.

SISTEMA DE PRESTIGIO — LA REVOLUCIÓN
─────────────────────────────────────
Umbral: 10.000B de Conciencia Total acumulada histórica
(el contador nunca baja aunque gastes Conciencia)

Cíclico e ilimitado. En cada Revolución:

PIERDES: toda la ⚡ actual y todos los colectivos.
CONSERVAS: heroes[], totalRevoluciones, concienciaTotal
GANAS: eliges 1 de 3 Héroes aleatorios sin repetición.
  - Los héroes no se repiten hasta haberlos conseguido todos.
  - A partir de la revolución 11 vuelven a aparecer todos.

Frases narrativas por revolución:
1ª → "La primera chispa siempre parece pequeña. La historia dirá lo contrario."
2ª → "Cada caída es una lección. El movimiento vuelve más fuerte."
3ª → "No es derrota. Es el ciclo natural de toda revolución."
4ª+ → "El pueblo que no olvida su historia está condenado a superarla."

- Luxemburg + Allende → Cada Revolución genera bonus extra de ⚡ inicial


FUERZAS ANTAGÓNICAS (Fase 3)
─────────────────────────────
Diseñadas en arquitectura desde Fase 1. Activadas en Fase 3.

💼 Presión Capitalista — permanente
  Barra que sube sola con el tiempo. Si llega al máximo
  reduce tu generación de ⚡. Compras mejoras para resistirla.

📰 Eventos Aleatorios — ocasionales
  Situaciones inesperadas con texto narrativo.
  Ejemplos:
  - "La prensa mainstream ataca la cooperativa. Pierdes 20%
    de ⚡/hora durante 2 min... a menos que tengas la Radio."
  - "El ayuntamiento intenta desalojar el Colectivo de Vivienda.
    El Sindicato Obrero puede bloquearlo."
  - "Un empresario ofrece financiación a cambio de influencia.
    Rechazar cuesta ⚡. Aceptar... también."


FIREBASE — ARQUITECTURA
────────────────────────
Proyecto: class-rising
Servicios activos:
  - Authentication con Google
  - Firestore Database (europe-west)

Archivo firebase.js — funciones exportadas:
  - loginConGoogle()
  - cerrarSesion()
  - escucharAuthEstado(callback)
  - guardarPartidaNube(userId, estado)
  - cargarPartidaNube(userId)

Flujo de autenticación:
  Usuario abre el juego
    │
    ▼
  ¿Está logueado?
    ├─ NO → muestra botón "Entrar con Google"
    └─ SÍ → carga partida desde Firestore
                │
                ▼
            Jugar
                │
                ▼
        Cada 5 segundos → guardar en localStorage + Firestore
                │
                ▼
        Usuario cierra → partida guardada en la nube

Guardado:
  - localStorage como respaldo local siempre
  - Firestore como guardado en nube si hay sesión activa
  - Clave localStorage: "conciencia-de-clase-v1"
  - Colección Firestore: "partidas/{userId}"

NOTAS TÉCNICAS
──────────────
- Stack: HTML + CSS + JavaScript puro con ES modules
- Sin frameworks ni librerías externas
- Editor: VS Code + Live Server + Claude Code
- Versiones: Node.js v24, Git v2.54
- Los scripts usan type="module" en index.html
- Las funciones globales se exponen via window._nombre
  para que los onclick del HTML puedan acceder a ellas
- renderizar() → actualiza números, disabled y barra progreso
- renderizarColectivos() → reconstruye cards (solo en acciones)
- actualizarBotonRevolucion() → muestra botón según concienciaTotal
- Bucle principal: 100ms
- Guardado: localStorage + Firestore cada 5 segundos
